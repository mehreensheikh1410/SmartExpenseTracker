# Smart Expense Tracker

Smart Expense Tracker is a Python application designed to help users manage their personal expenses and monitor their monthly spending.

## Overview

The application allows users to record expenses, organize them by category, track their spending against a monthly budget, and visualize spending patterns.

## Features

- Add and store expenses
- View recorded expenses
- Calculate total spending
- Set and track a monthly budget
- Calculate remaining budget
- Analyze spending by category
- Visualize expenses with graphs
- Delete expenses
- Persistent data storage using SQLite
